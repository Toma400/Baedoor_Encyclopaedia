# Contribution Cheatsheet
Here is the list of all steps that you ideally should care for, creating articles for particular
categories.

### General rules
- judge if linked article will be longer by starting from root `(/LINK)` or relative link `(../LINK)`,
  pick the one that is the shortest/more natural
- if the article (or its section) introduces new identifiable name or concept unique enough, include
  it in [index](/Loreum/Index.md)

### Backlinks
- should be separated by ` 〰️ ` character
- should always point to starting points `[💠](/Entrance.md) 〰️ [➰](/Loreum/Loreum.md)`
- should include whatever is above in repository tree (see subsections)

### Characters
- make sure to create [backlink](#backlinks), including:
  - `[🌸](../../Characters.md)` - general category backlink
  - `[🥮](../Ghloddish_Characters.md)` - specific character backlink
    - should be `cultural`, and if can't be defined, then in that order: `country, era, none`
    - make sure that emoji reflects respective subcategory
- include link to index [via rules](#general-rules), but also include one ideally in every
  character section (cultural, country, era)
  - if section doesn't exist, you can skip that or create a new one - make sure however to
    introduce it properly by doing all required linking
